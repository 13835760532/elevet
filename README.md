# 壹拾智检数智服务平台

壹拾智检数智服务平台（专业版 v2.0）是一套面向农产品质量安全业务的数智化管理前端。
平台围绕主体与产品建档、快速检测、任务协同、承诺达标合格证、农产品溯源、风险预警和
统计分析构建，并提供组织权限、消息通知、基础设施和 AI 风险问答等管理能力。

本仓库为平台管理端前端项目。页面菜单和数据权限由后端根据当前用户、角色和机构动态下发，
不同账号实际可见的功能可能不同。

## 页面概览

### 工作台

登录后默认进入“我的工作台”，集中展示：

- 农产品质量安全风险公告和阳性、不合格预警
- 待接收任务及任务接收入口
- 我执行的任务、我下发的任务及执行进度
- 按日期、方案、任务和主管单位筛选的任务跟踪信息
- 风险日报、月报订阅入口

### 核心业务模块

| 模块 | 主要功能 |
| --- | --- |
| 快检任务 | 工作方案管理、任务接收与转派 |
| 建档备案 | 生产经营主体建档、农产品建档、批量导入 |
| 快速检测 | 任务检测、非任务快检、检测结果登记与报告 |
| 合格证服务 | 合格证开具、收证、监管、查询、导出、详情和作废 |
| 农产品溯源 | 汇总产品、主体、检测和合格证信息，形成追溯链路 |
| 监管预警 | 监管预警大屏、快检统计、风险排行、趋势和公告 |
| 标准查询 | 农产品国标限量查询、检测指标推荐 |
| 用户与机构 | 分发关系、用户、角色和机构管理 |
| 系统管理 | 菜单、字典、短信、邮件、站内信、通知公告、审计日志和地区管理 |
| 基础设施 | 代码生成、数据源配置、表单构建、文件配置和文件列表 |
| AI 助手 | 使用自然语言查询地区风险、检测项目、月度趋势和阳性率 |

### 监管预警大屏

大屏根据当前地区、时间范围和数据权限汇总监管数据，主要包含：

- 监管机构、检测机构、生产经营主体等覆盖群体
- 任务下发量、完成量、完成率、快检样品量和检测项总量
- 合格证开具量与收证量
- 农产品类别、农产品、检测项和区域风险排行
- 全国地图、检测态势、农产品与检测项组合风险
- 风险公告及明细查看

### AI 助手

“小壹 AI 助手”提供农产品风险问答工作台，可围绕地区排名、阳性检出、检测项目和月份趋势
进行自然语言提问。页面提供推荐问法、自由输入和语音输入，并返回分析结论与后续关注方向。

## 开发环境

建议使用以下环境：

- Node.js 18 及以上版本，推荐 Node.js 20 LTS
- pnpm 8.6 及以上版本

安装依赖：

```bash
pnpm i
```

启动本地开发环境：

```bash
pnpm dev
```

该命令使用 `.env.local`，默认访问地址为 <http://localhost:48080>。

启动开发服务器模式：

```bash
pnpm dev-server
```

该命令使用 `.env.dev`。前端需要可用的后端接口才能完成登录、动态菜单加载和业务数据查询。

## 配置说明

常用环境变量如下：

| 变量 | 说明 |
| --- | --- |
| `VITE_APP_TITLE` | 浏览器标题和平台名称 |
| `VITE_BASE_URL` | 后端服务地址 |
| `VITE_API_URL` | 管理端接口前缀 |
| `VITE_BASE_PATH` | 前端部署基础路径 |
| `VITE_OUT_DIR` | 构建输出目录 |
| `VITE_APP_TENANT_ENABLE` | 是否启用租户功能 |
| `VITE_APP_CAPTCHA_ENABLE` | 是否启用登录验证码 |
| `VITE_UPLOAD_TYPE` | 文件上传方式 |
| `VITE_SOURCEMAP` | 是否生成源码映射 |

修改环境配置前，请确认目标后端、接口前缀和部署路径一致。不要把真实账号、密码、访问令牌或
生产环境密钥提交到仓库。

## 测试与检查

运行单元测试：

```bash

```

运行 TypeScript 类型检查：

```bash
pnpm ts:check
```

代码格式和样式检查命令会自动修改文件，执行前请确认工作区状态：

```bash
pnpm lint:eslint

```

## 构建与预览

构建预发布环境：

```bash
pnpm build:stage
```

构建生产环境：

```bash
pnpm build:prod
```

本地构建并预览：

```bash
pnpm preview
```

构建结果默认输出到 `dist/`，也可通过对应环境文件中的 `VITE_OUT_DIR` 调整。`dist/`、
`dist-prod/` 等构建产物目录不应手工编辑。

## 开发约定

- 页面放在 `src/views/`，可复用组件放在 `src/components/`。
- 接口按业务域放在 `src/api/<domain>/`，共享逻辑放在 `src/hooks/` 或 `src/utils/`。
- 优先使用 Vue 单文件组件和 `<script setup lang="ts">`。
- 使用 `@` 别名引用 `src/` 下的模块。
- 统一使用 2 空格缩进、单引号、无分号和无尾随逗号。
- 测试文件与实现就近放置，并使用 `*.test.ts` 或 `*.integration.test.ts` 命名。
- 修改共享类型、状态、路由或接口契约后，至少运行单元测试和类型检查。

## 权限与数据说明

系统使用后端动态菜单和数据权限。README 中列出的功能来自当前系统页面，最终可用范围仍以
登录用户的角色、所属机构、行政区划和后端配置为准。页面出现空态时，应先检查筛选条件、
数据权限和接口环境，不应仅根据空态判断功能不可用。
